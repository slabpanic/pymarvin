pymarvin
========

Python bindings for Tianji Marvin robot control, offline kinematics and interference
checks, using uv, CMake,
scikit-build-core and nanobind. The distribution and import names are both ``pymarvin``.

The package compiles the included SDK sources instead of loading vendor binary
libraries. Prebuilt wheels support Linux x86_64/aarch64 and Windows x64 on CPython 3.10–3.14.
